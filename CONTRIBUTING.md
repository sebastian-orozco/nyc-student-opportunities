# Contributing

Thanks for helping NYC students find opportunities!

## Suggest an opportunity

1. [Open a new issue](../../issues/new/choose) and pick **New opportunity**.
2. Fill in what you know. The program's own website link is the most important part.
3. A maintainer will review it and add it to the list.

We list opportunities that are open to NYC high school students: in-person programs anywhere in the city, virtual programs, and programs outside NYC that NYC students can attend. One-off events (fairs, info sessions) are welcome too.

## Report a change

Deadline moved, link broken, program closed? Open an issue with **Update an opportunity** and paste the program's link so we can find it.
